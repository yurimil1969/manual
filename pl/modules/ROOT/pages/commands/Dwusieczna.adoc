Dwusieczna( <Prosta>, <Prosta> )::
  Zwraca obie dwusieczne kątów utworzonych przez proste.

[EXAMPLE]
====

`++Dwusieczna(x + y = 1, x - y = 2)++` daje w wyniku _a: x = 1.5_ i _b: y = -0.5_.

====

Dwusieczna( <Punkt>, <Punkt>, <Punkt> )::
  Zwraca dwusieczną kąta utworzonego przez trzy punkty.

[EXAMPLE]
====

`++Dwusieczna((1, 1), (4, 4), (7, 1))++` daje w wyniku _a: x = 4_.

====

[NOTE]
====

Drugi punkt jest wierzchołkiem tego kąta.

====
