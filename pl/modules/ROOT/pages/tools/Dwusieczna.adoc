= Narzędzie Dwusieczna
:page-en: tools/Angle_Bisector
ifdef::env-github[:imagesdir: /en/modules/ROOT/assets/images]

Używając narzędzia:

* Wybierz trzy punkty (np. _A_, _B_, i _C_), by stworzyć dwusieczną kąta _ABC_ (punkt _B_ jest wierzchołkiem kąta).

lub


* Wybierz dwie proste, aby utworzyć dwusieczne kątów utworzonych przez te proste.

[NOTE]
====

* Wektory kierunkowe wszystkich dwusiecznych mają długość 1.
* Zobacz także polecenie xref:/commands/Dwusieczna.adoc[Dwusieczna].

====
