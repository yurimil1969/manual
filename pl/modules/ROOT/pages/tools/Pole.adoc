= Narzędzie Pole
:page-en: tools/Area

Używając narzędzia:

* Wybierz okrąg lub elipsę, by zmierzyć ich pole i wyświetlić je w _Widoku Algebry_ oraz stworzyć tekst dynamiczny w _Widoku Grafiki_ zawierający tą samą wartość.
* Wybierz wielokąt, by zmierzyć jego pole i stworzyć tekst dynamiczny w _Widoku Grafiki_ zawierający tą samą wartość.
